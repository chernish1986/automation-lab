# AI & Business Automation — Portfolio Projects

This repository contains sanitized, demonstrative implementations that reflect the kinds of systems I build for clients: AI workflow automation, Python backends, WebSocket services, Telegram automation, web scraping, retail operations tooling, and crypto/arbitrage infrastructure.

## Featured projects

1. **AI & Business Automation with n8n, APIs and AI Agents**
   - n8n-style workflow design
   - webhook/API orchestration
   - AI classification and routing
   - CRM/Sheets/Telegram integration patterns

2. **Real-Time Python API & WebSocket Backend**
   - FastAPI-style async backend patterns
   - WebSocket event processing
   - reconnect/retry logic
   - structured logging and health checks

3. **Telegram Automation Bot**
   - event-driven alerts
   - status reports
   - API-backed notifications
   - configurable message routing

4. **Automated Web Scraping & Monitoring**
   - structured extraction
   - normalization and deduplication
   - change detection
   - export/report hooks

5. **Retail Network Automation & Reconciliation**
   - store-level calculations
   - balance reconciliation
   - consolidated reporting
   - discrepancy detection

6. **Multi-Exchange Crypto Arbitrage & Trading Infrastructure**
   - exchange abstraction
   - spread monitoring
   - fees/funding-aware opportunity checks
   - hedge/reconciliation concepts
