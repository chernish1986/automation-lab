# Multi-Exchange Crypto Arbitrage & Trading Infrastructure

Sanitized demo of a multi-exchange monitoring architecture that compares prices, estimates net spread after fees, and produces hedge opportunities without placing real orders.

## Demonstrated skills
- exchange abstraction
- REST/WebSocket market data concepts
- fee-aware spread calculation
- hedge opportunity validation
- risk and reconciliation concepts
- structured logging and configuration

This public demo does not contain exchange API keys, private endpoints, live-account identifiers, or proprietary production logic.
